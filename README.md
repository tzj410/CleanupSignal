Live website: https://cleanupsignal.pages.dev/

## Run and verify

Python 3.11+ and Node 24 are used. There are no runtime npm dependencies. Pinned Playwright is a development-only dependency for repeatable browser tests.

```sh
python3 scripts/build_worker.py
npm run check
npm test
python3 -m unittest discover -s tests -v
python3 scripts/pipeline.py --check
```

59 automated parser/backend tests currently cover parsing, status safety, source failures, company isolation, invitations, seats, billing state/signatures, checkout deduplication, unsubscribe and email queue retries. Provider integrations are mocked in backend tests; no successful live checkout or email delivery is claimed.

For the public frontend only:

```sh
python3 -m http.server 8000 --directory public
```

A static server does not execute the account API. Use Pages Functions/Workers for the complete runtime. Build output is generated by `npm run build`; edit `server/` and rebuild rather than editing `public/_worker.js` directly.

Live research refresh:

```sh
python3 scripts/pipeline.py
```

`SAM_API_KEY` is supplied only in the hosted reporting workflow. The frontend selects the newest valid public snapshot between its bundle and GitHub main. Reports carry their generation date.

GitHub CI tests all pushes/PRs. Local and D.C. source checks are scheduled hourly at minute 17 (UTC). SAM.gov successful discovery is reused for 24 hours to protect the federal request budget; 429 responses retain their 24-hour cooldown. GitHub scheduling can be delayed, and open pages require reloading to show newly published data. EPA checks revalidate known selections rather than discovering every new grant. The alert workflow runs only when its automation secret is configured. The new Pages deployment workflow requires a scoped `CLOUDFLARE_API_TOKEN`; without it, deployment is explicitly skipped. No automatic code-deployment claim is made until that secret is installed and a run succeeds.

Keep credentials and customer information outside this public repository. No paid account, subscriber enrollment, customer outreach or revenue is claimed. More verified Maryland/Virginia procurement coverage, provider activation, real end-to-end payment/email testing, mobile/Safari QA, support operations and commercial seller details remain necessary for a paid self-service launch.
